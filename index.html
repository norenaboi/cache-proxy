OpenRouter Cache Proxy

Source

Point your OpenAI-compatible client at either endpoint below. The proxy adds prompt-caching breakpoints to eligible messages, then forwards the request to OpenRouter. Use /v2 when a stable prompt should remain cached for one hour. That is the entire job — no prompt rewriting, no inspection for any other purpose, no stored request bodies or API keys.

Default cache · approximately 5 minutes /v1/chat/completions
1-hour cache · best for repeated stable prompts /v2/chat/completions

You need to keep the prompt stable, this means:

  • No lorebooks.
  • No prefills.
  • Max context set to 0.
