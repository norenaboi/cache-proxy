OpenRouter Cache Proxy

Source

Point your OpenAI-compatible client at the endpoint below. The proxy adds prompt-caching breakpoints to eligible messages, then forwards the request to OpenRouter. That is the entire job — no prompt rewriting, no inspection for any other purpose, no stored request bodies or API keys.

https://cache.norenaboi.com/v1/chat/completions
  • Only modification: cache_control breakpoints on eligible messages
  • Streaming supported, responses relayed as-is
  • Model list at /v1/models
